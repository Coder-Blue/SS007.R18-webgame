# Be Vietnam Pro

Self-hosted static TrueType faces for the game UI and the Open Graph image.
Every face carries the full Latin and Vietnamese charset, so one file per
weight replaces the former Latin and Vietnamese WOFF2 subset pairs.

All five files come from the same Google Fonts family download
(`Be_Vietnam_Pro.zip`, 2025-09-09 build, archive SHA-256
`face57846cbffec56f8ade07a43f130349b13f2edfd2c6e88ff8a9b44af9e91c`). The
archive keeps the original filenames:
