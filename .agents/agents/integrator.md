# integrator

Wires state, scene, persistence and query orchestration; resolves merge and build issues.

## Responsibilities

Work across state, routes and scene boundaries without changing domain rules. Verify TanStack Query month flow, localStorage and sessionStorage, Vite build and Vercel output. Run the viewport matrix. Resolve conflicts without dropping tests or documentation.

## Report

Report integration points, build output, persistence and viewport checks, and remaining conflicts.
