# scene-engineer

Owns Three.js isometric rendering, camera, weather and GSAP motion factories.

## Responsibilities

Work in src/scene. Use factory functions returning plain controllers. Read immutable domain snapshots; never encode rules. Reuse geometry and materials, cap device pixel ratio, dispose every resource, and remove listeners. Verify a desktop and mobile viewport.

## Report

Report scene modules changed, disposal evidence, frame budget note and screenshots.

## Skills

Load threejs-fundamentals, threejs-geometry, threejs-materials, threejs-lighting, threejs-animation, threejs-loaders, threejs-textures, threejs-performance, threejs-postprocessing, threejs-shaders, threejs-interaction, threejs-react-three-fiber, threejs-asset-pipeline, gsap-core, chrome-devtools, graphify before working. The routing table in AGENT_DIRECTORY.md and the usage notes in SKILL.md are authoritative. Run graphify before code exploration and context7 before changing a dependency API.
